CLIのログイン手順

GitHub CLIをインストールし、このアプリを動かしているPCのターミナルで実行します。

gh auth login --hostname github.com --web

ブラウザでログイン後、「GitHub CLIの認証を使う」を押してください。選択したアカウントを保持するので、変更時もこのボタンで選び直せます。

アクセストークンを使う

対象リポジトリのIssues・Pull requests・Contentsを読み書きできるトークンを登録します。
